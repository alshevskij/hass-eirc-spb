Интеграция Home Assistant для личного кабинета ЕИРЦ Санкт-Петербурга / ПСК (IKUS).

**Статус:** ранняя разработка. Версия 2026.11.0 — первый этап: авторизация, выбор лицевых счетов и получение показаний приборов учёта.

## Возможности

- Вход по номеру телефона и паролю.
- Подтверждение входа кодом из email, если IKUS запрашивает второй фактор.
- Выбор одного или нескольких лицевых счетов.
- Получение последних принятых показаний счётчиков.
- Получение текущего периода приёма показаний.
- Обновление данных каждые 30 минут.
- Отдельное устройство Home Assistant для каждого лицевого счёта.

## Установка через HACS

1. Откройте HACS → Интеграции.
2. Добавьте пользовательский репозиторий alshevskij/hass-eirc-spb с категорией Integration.
3. Установите «ЕИРЦ Санкт-Петербурга».
4. Перезапустите Home Assistant.
5. Добавьте интеграцию через Настройки → Устройства и службы → Добавить интеграцию.

Для ручной установки скопируйте каталог custom_components/eirc_spb в config/custom_components/eirc_spb.

## Безопасность и ограничения

Токены сессии и пароль сохраняются в конфигурационной записи Home Assistant. Не публикуйте журналы и HAR-файлы без удаления cookies, токенов, персональных данных и идентификаторов лицевых счетов.

Интеграция обращается к API IKUS, используемому веб-личным кабинетом. Техническая доступность API сама по себе не означает разрешения на автоматизированное взаимодействие. Перед публичным распространением и регулярным использованием проверьте действующие условия IKUS и применимые ограничения.

## Следующие этапы

Платёжные операции не включены в эту версию: endpoint создания платежа и проверка статуса требуют отдельной проверки на реальном аккаунте.
